# Demon's Maze

Игра на Unity с процедурным лабиринтом, пятью классами персонажей и боями с демонами.

## Запуск

1. Добавьте папку проекта в Unity Hub.
2. Откройте проект в Unity **6000.6.0f1**.
3. Откройте сцену `Assets/Scenes/DemonsMaze.unity` и нажмите Play.
4. В меню нажмите «Играть» и выберите класс.

## Управление

- **WASD** — движение.
- **Мышь** — направление взгляда.
- **Левая кнопка мыши** — атака.
- **Пробел** — уклонение.
- **Esc** — пауза.

В репозитории находятся исходники, ресурсы, пакеты и настройки проекта. Кэш Unity, логи, локальные настройки редактора и сборки исключены через `.gitignore`.
